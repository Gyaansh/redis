# Redis

A hands-on learning repository for understanding and working with **Redis** using Node.js.

I'm learning Redis through the **Redis series by Chai aur Code**, while implementing the concepts and examples myself along the way.

The goal of this repository is not just to learn Redis commands, but to understand how Redis can be used in real-world backend applications.

---

## 📚 What is Redis?

Redis is an **in-memory data store** commonly used as:

- A database
- Cache
- Message broker
- Queue
- Pub/Sub system
- Session store
- Real-time data store

Because Redis primarily works with data in memory, it can provide very fast read and write operations.
